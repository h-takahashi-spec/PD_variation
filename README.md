# 取調室のジレンマ v2（授業用・一回限りの囚人のジレンマ＋理由のAI分類）

いろいろな「相棒」（こわそうなヤクザ／優しそうな女性／宇宙人／かわいいロボット／柴犬／無機的なコンピュータ／子ども）と、
1人ずつ一度きりの囚人のジレンマを行う 3D ゲームです。ジレンマ劇場と同じ作りにしました。

- 相棒ごとに **選択 → 相棒の予想 → 判断の理由（15文字以上）** を書かせます
- 送信するとすぐに AI が理由を分類し、本人の終了画面にコメントつきで出ます
- **結果ページ**（`results.html`）で、クラス全体の傾向と全員の理由カードをその場で見られます（15秒ごとに自動更新）
- データは Google スプレッドシートに集まり、ページは GitHub Pages で公開します

```
index.html        … 学生が遊ぶページ
results.html      … 結果ページ（学生も見られる）／先生モードは results.html?t=1
admin.html        … 旧版のURL用（results.html?t=1 に移動するだけ）
config.js         … 設定（送信先URLなど）← ここだけ書き換える
js/common.js      … 分類の定義・通信・デモモード
js/game.js        … ゲーム本体（world.js, characters.js は3D）
js/results.js     … 結果ページ・先生モード
lib/three.min.js  … 3D描画ライブラリ（同梱）
gas/Code.gs       … Google Apps Script（保存・AI分類・先生の操作）
```

## 結果ページで見られるもの

| 表示 | 内容 |
|---|---|
| 数字 | 参加人数／黙秘した割合／「相棒は黙秘する」と予想した割合／予想と同じ手を選んだ割合 |
| 相棒別の黙秘率 | 棒＝自分が黙秘した割合、オレンジの線＝相棒は黙秘すると予想した割合 |
| 予想と選択の組み合わせ | 信じて協力／出し抜く／それでも協力／身を守る、の4つを相棒別に |
| 理由の分類（AI） | 相棒別の分類の割合、黙秘した人と自白した人の比較、主・副あわせた割合 |
| 心の知覚（AI） | 理由が相棒の「意図・能力（エージェンシー）」と「感情・痛み（エクスペリエンス）」のどちらに触れていたか |
| みんなの理由 | ニックネーム・選択・予想・理由・AIの分類とコメント。相棒・選択・分類・心の知覚で絞り込めます |

グラフの帯を押すと、下の理由カードがその組み合わせに絞られます（例：柴犬×感情的）。各グラフの「数で見る」で表も出ます。
「投影モード」で文字が大きくなります（`results.html?t=1&big=1` でも可）。

### AIの分類

- **主な分類（1つ）**と**ほかに含まれる考え方（最大2つ）**、それぞれ理由つき
  - 合理的：刑期の比較、相棒の出方の予測にもとづく損得
  - 感情的：恐れ・同情・かわいそう・好き嫌いなど
  - 規範的：信頼・約束・裏切るべきでない・子どもを守るべき など
  - 認知バイアス：ステレオタイプ・擬人化・フォールス・コンセンサス など（名前を1つ）
  - 判定不能
- **心の知覚**：意図・能力／感情・痛み／両方／なし
- **学生への一言**（40〜80字）

「ゲーム理論の答え（自白）から外れたこと」や「見た目から相棒の出方を推測したこと」だけではバイアス扱いしないよう指示してあります。
定義を変えるときは、`gas/Code.gs` の `SYSTEM_PROMPT`・`CATS`・`MINDS` と、`js/common.js` の `CATS`・`MIND` を同じ名前にそろえてください。

## 準備（初回だけ・20分ほど）

### 1. スプレッドシートと Apps Script

1. **新しい** Google スプレッドシートを作る（個人の Google アカウントがおすすめ。大学アカウントだと「全員」に公開できないことがあります）
2. **拡張機能 → Apps Script** を開き、`gas/Code.gs` の中身を丸ごと貼り付けて保存
3. 左の ⚙ **プロジェクトの設定 → スクリプト プロパティ** に追加
   - `TEACHER_PASSWORD`：先生モードのパスワード
   - `OPENAI_API_KEY`：OpenAI の API キー（既定モデル `gpt-4.1-mini`。`OPENAI_MODEL` で変更可）
   - Claude を使う場合は `AI_PROVIDER` = `anthropic` と `ANTHROPIC_API_KEY`（既定モデル `claude-haiku-5-5`。`ANTHROPIC_MODEL` で変更可）
   - ジレンマ劇場と同じキーをそのまま使えます
4. 関数 `setup` を選んで ▶実行 → 権限を承認（シート `log` ができます）
5. 関数 `testClassify` を実行し、ログに分類結果が出ることを確認（APIキーの確認）
6. **デプロイ → 新しいデプロイ** → 種類：**ウェブアプリ**／次のユーザーとして実行：**自分**／アクセスできるユーザー：**全員**
7. 表示された `https://script.google.com/macros/s/……/exec` をコピー

> 旧版（v1）のスプレッドシートに貼り替えても動きます（足りない列は右端に自動で足されます）。ただ旧版の行には理由がないので、新しいシートで始めるほうがすっきりします。

### 2. config.js に URL を貼る

```js
GAS_URL: 'https://script.google.com/macros/s/……/exec',
```

### 3. GitHub Pages で公開する

1. GitHub のリポジトリ（既存の `pd-game` を上書きでも可）に、このフォルダの中身をアップロード（`gas/` は入れなくても可）
2. **Settings → Pages** → Branch を **main / (root)** にして Save
3. 公開URL
   - 学生用：`https://<ユーザー名>.github.io/pd-game/`
   - 結果：`https://<ユーザー名>.github.io/pd-game/results.html`
   - 先生用：`https://<ユーザー名>.github.io/pd-game/results.html?t=1`

### 4. 動作確認

1. 学生用ページで、学籍番号 **TEST**・ニックネーム自由で最後まで遊ぶ（`?skip=1` を付けるとルール説明を飛ばせます）
2. 終了画面に「送信完了」と、AIの分類カードが出ることを確認
3. 先生用ページでパスワードを入れる → 「TESTで始まる学籍番号を除く」を外すと、自分の回答が見えます

`GAS_URL` が空のままだと **デモモード**（このブラウザの中だけに保存、架空の24人分のサンプル回答つき、先生パスワード `demo`、分類はキーワードによる簡易判定）で動きます。画面の確認用です。

## 授業での流れ（例）

1. 学生用URL（QR）を配る → 各自が学籍番号とニックネームを入れて開始（10〜15分）
2. 先生は `results.html?t=1` を開いてパスワードを入れ、「投影モード」でスクリーンへ。15秒ごとに更新されます
3. 遊び終えた学生は終了画面の「クラスの結果を見る」から結果ページへ（遊んでいない端末では結果は見えません）
4. 全員終わったら「**未分類の理由をAIで分類**」を一度押す（一斉送信で自動分類が混み合って失敗した分を、10件ずつまとめて分類します）
5. 柴犬・子どもで「感情・痛み」、ヤクザ・コンピュータで「意図・能力」が多いか、などを見ながら議論
6. 「参加者名簿のCSV」で参加点をつける

### 先生モードでできること

- 各カードの **分類を直す**（「先生」として優先して集計）／**学生から隠す**（不適切な書き込み用）
- 絞り込み：TEST除外、各学生の最新プレイだけ、日付、隠した理由も表示
- **すべて分類し直す**（プロンプトを変えたあとなど。2回押すと実行）
- CSV：1選択＝1行（分析用）／1人＝1行（相棒ごとの協力・予想・提示順・考えた時間・分類・心の知覚・理由が横に並ぶ）／参加者名簿

## ゲームの仕様

- ルールの導入（3Dの取調室と刑期ブロックの演出）→ 理解度チェック1問 → 7人の相棒と各1回
- 相棒の順番、黙秘／自白ボタンの左右は学生ごとにランダム
- 各相棒の後に「供述調書」画面：相棒の予想（黙秘／自白）と理由（`MIN_REASON` 文字以上）。予想を尋ねないときは `ASK_EXPECT: false`
- 相棒の選択は全キャラ同じ確率（初期値50%）のランダム。プレイ中は見せず、最後に「判決」としてまとめて開示（`REVEAL: 'none'` で開示なし）
- 刑期：両者黙秘 1年ずつ／自分だけ自白 0年・相棒10年／両者自白 5年ずつ（`config.js` と `Code.gs` の `PAYOFF`）
- 送信は最後にまとめて1回。失敗しても自動で再試行し、次にページを開いたときにも再送します

## 記録される列（シート `log`、1選択＝1行）

| 列 | 内容 |
|---|---|
| row_id / session_id / attempt | 行のID／1回のプレイのID／その端末で何回目か |
| student_id / nickname | 学籍番号（結果ページには出ません）／ニックネーム |
| trial / character_id / character_name | 何番目の相手か／相手 |
| choice / cooperate | silent（黙秘）=1 ／ confess（自白）=0 |
| expect / expect_cooperate | 相棒の予想（silent=1 ／ confess=0） |
| reason / reason_len / rt_reason_ms | 理由／文字数／書くのにかかった時間 |
| rt_ms / rt_first_ms / changed_mind / viewed_table | 決めるまでの時間／最初に押すまで／選び直した回数／刑期の表を開いた回数 |
| partner_choice / my_years / partner_years | 相手の（ランダムな）選択と刑期 |
| comp_answer / comp_correct | 理解度チェック |
| button_order / device / screen / user_agent ほか | 表示条件と端末 |
| ai_primary / ai_tags / ai_bias / ai_mind / ai_comment | AIの分類（主・副・バイアス名・心の知覚・一言） |
| ai_json / ai_model / ai_at | 判定理由を含む全体／使ったモデル／分類した時刻 |
| teacher_primary / hidden | 先生が直した分類／学生から隠した（1） |

## 注意

- 結果ページは誰でも開けます（遊んでいない端末には中身を出しません）。学籍番号は先生モードでしか出ません
- `Code.gs` を直したら **デプロイ → デプロイを管理 → ✏ 編集 → バージョン：新バージョン → デプロイ**（URLは変わりません）
- Chrome で複数の Google アカウントにログインしていると、URLに `/u/1/` などが入って開けないことがあります。シークレットウィンドウで確認してください
- AIの利用料の目安：60人×7理由＝420件で、gpt-4.1-mini なら数十円程度です
- キャラクターはすべてプリミティブ形状で組んだオリジナル造形です
